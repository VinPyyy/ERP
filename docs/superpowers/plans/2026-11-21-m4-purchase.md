# M4 采购链路 实现计划

> **面向 AI 代理的工作者：** 必需子技能：executing-plans 内联执行。步骤用复选框跟踪。

**目标：** 询价→采购订单→入库（动库存）→退货（出库）四单据全链路 + 作废冲正 + 前端四组页 + 冒烟。

**架构：** 复用 M3 骨架：单据头继承 `BaseDocEntity`（条件状态 UPDATE 防并发，影响 0 行→10002）、动库存只走 `StockService` 门面（BizType PUR_IN / PUR_RETURN_OUT）、冲正走 `reverse`、溢收读 `purchase.over.receive.ratio`、盘点锁经新增 `inventory.api.CountLockGuard` 在各审核入口 EXISTS 校验（spec §3d）。

**技术栈：** Spring Boot 3 + MyBatis-Plus（表已在 V1，零迁移）+ Sa-Token 权限点（V2 已种子 purchase:*）+ Vue3/Element Plus。

**规格：** `.scratch/erp-phase1/spec.md` §2.4/§4.1/§4.2/§8-11/12/13 + `issues/05`；前置 `docs/inventory/stock-model.md`。

## 全局约束

- 状态机：DRAFT(10)→AUDITED(20)→COMPLETED(30)/VOIDED(50)；行 line_status 10/30/40；全部条件 UPDATE。
- 溢收：`done_qty ≤ qty×(1+ratio)`，ratio 只作用采购入库；销售超发严禁（M5）。
- 带 source 入库单仓库必须 = 订单仓库（§8-12 硬校验）；入库价默认带订单价可改（§8-11）。
- 退货：有原单→价不可改、累计退货 ≤ 原入库量；无原单→价手录、成本按当前均价。
- 作废逆序（§4.2）：订单有非作废下游入库→拒；入库有非作废下游退货→拒；冲正后 done_qty 回减。
- 每用例收尾 `StockInvariantAsserter.assertConsistent()`；TDD 红→绿；`mvn test`+`npm run build`+冒烟落地。
