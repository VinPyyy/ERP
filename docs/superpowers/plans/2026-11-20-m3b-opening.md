# M3b 期初单（CRUD/审核/作废冲正 + Excel 导入）实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development 或 executing-plans 逐任务实现。步骤用复选框跟踪。

**目标：** 期初库存单全生命周期（草稿→审核→可作废）+ Excel 导入向导，成为第一个真实驱动 `StockService` 的业务场景。

**架构：** `OpeningService` 走统一状态机（条件 UPDATE 防双击）；审核逐行调 `StockService.inbound(BizRef(OPENING,...))`（批次/SN 物化复用门面）；作废调 `StockService.reverse` 按原流水快照冲正（ADR-0003）；Excel 导入全量校验、有错整批不落库（对齐 M2 口径），批号/SN 文本落行、物化留给审核。

**技术栈：** Spring Boot 3 + MyBatis-Plus + EasyExcel 4.x（`basedata.excel` 已有同型实现可参照）。

**规格：** `.scratch/erp-phase1/spec.md` §2.3（inv_opening/item）、§3b/§3c/§6-M3 + `issues/04`。前置：[m3a 已完成](2026-11-20-m3a-inventory-core.md)。总览：[索引](2026-11-20-m3-inventory-opening.md)

## 全局约束

- 一仓一期初单（头 warehouse_id）；同仓库×SKU 只允许一张**非作废**期初行（审核与导入都校验）。
- 审核后该 wh×SKU 已有后续流水（非本单）→ 禁作废，报 30003。
- 取号 `DocNoService.nextNo(DocType.OPENING)`（QC 前缀），草稿创建时取。
- 期初均价 `cost_price NOT NULL` 允许 0；数量 > 0。
- 每个测试收尾调用 `StockInvariantAsserter.assertConsistent()`。
- TDD；`mvn test` 全绿。

## 审查重点（Review Focus）

1. 重复期初：同 wh×SKU 第二张非作废单审核必须拒绝 → 任务 1 `duplicateOpeningRowRejected`。
2. 已被消耗禁作废：审核后出库一笔再作废期初 → 30003 → 任务 1 `voidWithSubsequentFlowRejected`。
3. 冲正幂等：同一期初单作废两次 / reverse_flow_id 已占用 → 拒绝 → 任务 1 `voidTwiceRejected`。
4. 导入全有全无：任一行错整批不落 + 行号级错误清单 → 任务 2 `anyErrorRejectsWholeFileRowReported`。
5. 审核重放一致：期初审核+作废后 replay-check 仍零差异 → 任务 1/2 收尾断言。
