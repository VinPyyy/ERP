# 库存计价采用移动加权平均，粒度为仓库×SKU

系统管理批次和 SN，但计价不按批次：入库重算均价、出库按当前均价结转，均价粒度为仓库×SKU。选它是因为批次/SN 定位是追溯而非计价，批次计价会把出入库、作废冲正、报表全部复杂化，而中小规模贸易业务对单品单批次精确毛利没有硬需求。

## Considered Options

- **批次实际成本计价**：每批次记实际采购价，出库按所选批次结转。毛利最真实且与批次管理天然契合，但出库必须指定批次、拆批并批的成本分摊复杂、库存价值核算难度翻倍。被拒：违背"批次只追溯不计价"的既定决策。
- **FIFO 计价**：按入库时间层结转，需独立库存分层账，与物理批次管理重复建设。被拒：实现复杂度最高。

## Consequences

- 出库不改变均价（量额同比例减），"退货导致均价回退"不存在。
- 单品单批次的真实毛利被平滑掉；三期毛利分析口径 = 销售收入 − 出库结转均价成本。
- 计价方法一旦上线极难更换（历史流水需重算），故立此 ADR。
