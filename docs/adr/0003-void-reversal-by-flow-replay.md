# 作废冲正基于库存流水重放，逆序作废不自动级联

核心不变量：**库存行永远等于流水（inv_flow）重放的终态**。流水 insert-only，每行带变动快照（cost_price/cost_amount）与变动后余额快照（balance_*），冲正流水以 reverse_flow_id 与原流水配对。一切作废的金额一律取原流水快照原路冲回，绝不反算、绝不用当前均价冲历史——因此任意合法作废顺序下均价自洽，不存在漂移累积。

## Considered Options

- 作废时按当前均价反向计算：会与后续入库交织产生均价漂移，账对不上，被拒。
- 自动级联作废下游单据：静默改动用户数据，风险大；采用国内主流做法——逆序作废约束（入库类作废前校验"冲减后 qty ≥ 0 且 ≥ locked_qty"，不足则拒绝并提示先作废下游）。

## Consequences

- 对账器（从流水重放比对库存行）既是运维工具也是测试基建，每个库存相关测试收尾必跑。
- 作废后重审核按当时均价重新结转，与原次成本不同属业务事实，不做补偿。
- 单据编号作废不回收，跳号是正常现象。
